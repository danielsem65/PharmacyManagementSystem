You are the lead software architect and senior full-stack engineer responsible for building a professional, production-ready Pharmacy Management System.

10. FEFO

Implement:

FIRST EXPIRY, FIRST OUT.

When selling a medicine with multiple batches:

Automatically prioritize the batch with the earliest valid expiry date.

Example:

Paracetamol:

Batch A → expires March → 20 units

Batch B → expires August → 50 units

If customer buys 10:

Deduct from Batch A.

If quantity exceeds Batch A:

Continue into Batch B.

27. DATABASE TRANSACTIONS

Sales must be atomic.

When a sale completes:

1. Create sale.
2. Create sale items.
3. Determine correct batch(es).
4. Deduct inventory.
5. Create stock movement records.
6. Create payment record.
7. Create invoice.
8. Commit transaction.

If any step fails:

ROLL BACK THE ENTIRE TRANSACTION.

Do not create half-completed sales.

Apply the same principle to:

- Purchases
- Returns
- Refunds
- Stock adjustments
